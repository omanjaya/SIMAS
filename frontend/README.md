# SMP Saraswati Attendance Frontend

This directory contains the Next.js 15 frontend for the SMP Saraswati Denpasar face-recognition attendance system.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 4
- shadcn/ui component library
- Sonner toast notifications
- Recharts for analytics

The UI has been rebranded from the original template and now focuses solely on the needs of the attendance platform.
