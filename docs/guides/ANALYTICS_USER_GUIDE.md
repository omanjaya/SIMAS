# Analytics Dashboard User Guide

## Accessing Analytics
1. Login as admin
2. Navigate to "Reports & Analytics" from the sidebar
3. Select date range and filters

## Available Reports

### 1. Attendance Trends
Shows daily/weekly/monthly attendance patterns.

**How to use**:
- Select date range using the date picker
- Choose grouping (daily/weekly/monthly) from the dropdown
- Filter by department (optional)
- Switch between line/bar chart views
- Export to CSV/Excel using the export button

**Insights**:
- Identify attendance patterns and trends
- Spot low-attendance days or periods
- Compare departments performance
- Monitor overall attendance rates

**Chart Features**:
- Line chart showing present, late, and absent employees over time
- Bar chart view for easier comparison
- Summary statistics showing average attendance rate
- Peak and lowest attendance dates

### 2. Overtime Analysis
Analyzes employee overtime hours and patterns.

**How to use**:
- Select date range
- Filter by department or specific employee (optional)
- Toggle between "By Employee" and "By Department" views
- Export data to CSV/Excel

**Insights**:
- Identify employees with excessive overtime
- Analyze departmental overtime patterns
- Monitor workload distribution
- Plan staffing adjustments

**Chart Features**:
- Horizontal bar chart for top 10 employees by overtime
- Pie chart showing overtime distribution by department
- Summary statistics showing total overtime hours
- Average overtime per employee metrics

### 3. Leave Balance Forecast
Projects annual leave balances and identifies risks.

**How to use**:
- Select forecast year from the dropdown
- Filter by department (optional)
- Review risk levels (high/medium/low)
- Export data to CSV/Excel

**Insights**:
- Identify employees with low leave balances (high risk)
- Plan leave allocations and approvals
- Forecast future leave shortages
- Monitor leave usage patterns

**Features**:
- Color-coded risk levels (red = high, yellow = medium, green = low)
- Forecast exhaustion dates for each employee
- Summary statistics showing total leave taken/pending
- Detailed employee-level breakdown

### 4. Payroll Cost Analysis
Analyzes payroll expenses across departments and positions.

**How to use**:
- Select date range
- Filter by department (optional)
- Switch between "By Month", "By Department", and "By Position" views
- Export data to CSV/Excel

**Insights**:
- Monitor monthly payroll costs
- Compare departmental expenses
- Analyze position-based salary distributions
- Plan budget allocations

**Chart Features**:
- Bar chart showing gross, allowance, and deduction breakdowns
- Pie chart for departmental cost distribution
- Horizontal bar chart for position-based analysis
- Summary statistics showing total payroll costs

## Exporting Data

### CSV Export
Click "Export CSV" to download reports in comma-separated values format.
- Files are named with report type and timestamp for easy tracking
- Compatible with Excel, Google Sheets, and other spreadsheet applications
- Contains all visible data in the current view

### Excel Export
Click "Export Excel" to download reports in Microsoft Excel format.
- Files are named with report type and timestamp
- Preserves formatting and data types
- Multiple sheets for complex reports

## Filtering and Customization

### Date Range Selection
- Use the date picker to select custom date ranges
- Choose from predefined ranges (this month, last month, this year, etc.)
- Date ranges automatically adjust available data

### Department Filtering
- Filter reports by specific departments
- "All Departments" option shows organization-wide data
- Department filter applies to all report types

### Grouping Options
- Daily: Shows data for each day in the selected range
- Weekly: Groups data by week for trend analysis
- Monthly: Groups data by month for high-level overview

## Performance Tips

1. **Optimal Date Ranges**:
   - For detailed analysis, use shorter date ranges (1-3 months)
   - For trend analysis, use longer ranges (6-12 months)
   - Very long date ranges may affect loading times

2. **Filtering Best Practices**:
   - Apply department filters to reduce data volume
   - Use specific employee filters for individual analysis
   - Combine filters for targeted insights

3. **Export Recommendations**:
   - Export large datasets during off-peak hours
   - Use CSV for simpler analysis needs
   - Use Excel for complex data manipulation

## Troubleshooting

### Common Issues

1. **Slow Loading Times**:
   - Reduce date range
   - Apply department filters
   - Refresh the page

2. **Missing Data**:
   - Verify date ranges include relevant periods
   - Check department filters
   - Confirm employee status (inactive employees may be excluded)

3. **Export Failures**:
   - Try smaller date ranges
   - Refresh and retry
   - Contact system administrator if issues persist
